# Provenance

This Skill generalizes reusable practices from iteratively reviewed HTML teaching presentations. The source experience covered narrative order, plain-language titles, evidence placement, sourced installation imagery, process-flow diagrams, CSS overflow, interactive scientific viewers, user feedback records, browser-level interaction checks, and repeated learner failures caused by abstract candidates, unnamed objectives, and mathematically inconsistent multi-objective illustrations.

The Skill and slide scaffold were rewritten for reuse across topics. Course text, scientific data, structure files, project screenshots, project code, and other project-only assets are not included. The starter HTML is original and has no external runtime dependency.

This candidate adds a reusable title-language rule derived from a user-reviewed supramolecular chemistry deck: scientific slide titles should name the concrete object, phenomenon, relationship, or question; presentation workflow and learner actions belong in subtitles, controls, or presenter notes. The examples in the rule are general anti-patterns, not project content.
