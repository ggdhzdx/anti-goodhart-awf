# 科学文章通用写作原则

这些规则适用于不同学科和载体。按文章目的、读者背景和证据类型选择
相关规则，不把某一项目的名称、结论或参数推广成普遍事实。

## 1. 先说明对象，再陈述性质

让读者一开始就知道“谁的什么”。修饰语要有明确对象，代词要能找到
对应名词；比较时写出比较双方和比较维度。定义多个对象时，同时交代
影响理解的来源、归属和彼此关系。

## 2. 新概念首次出现时完成最低必要解释

术语、缩写和符号在使用前或首次使用处解释。解释至少回答：它指什么、
在本文中起什么作用、读者应怎样理解其变化。只展开缩写通常不够。

## 3. 用具体参与者、动作和关系替代抽象话

让读者看见“谁与谁发生了什么”。将“环境更有利”“状态改变”“性能更好”
落实为具体对象、变化、过程和判断依据。专业术语后可补一句直观解释，
不要用另一个陌生术语替代说明。

## 4. 补齐原因与结果之间的关键环节

机制说明采用以下顺序：

1. 哪个结构、条件或变量发生变化；
2. 它如何改变具体过程；
3. 数据显示了什么结果；
4. 该结果可能影响什么后续过程。

“因此”和“从而”不能代替缺失的物理、化学或统计依据。直接测量、数据
解释、工作假设和推测要使用不同的证据强度。

## 5. 指标先讲用途和读法（大同行导读），再讲公式与定量基准

复杂指标使用两层解释：

- 第一层用平实学术语言说明该指标度量什么物理、化学、生物或统计特征，
  数值变大或变小代表什么趋势（首次引入非标准或跨学科指标时，先用一两句话
  交代直观图景）；
- 第二层再给判据、符号、公式、参数和实现细节。

定义后紧接着说明它怎样回答本文问题。公式中的每个符号在公式附近解释，
结果表中的指标在表格出现前介绍。凡涉及核心性能、效率、产率或计量比指标，
应视学科需要交代理论上限基准、参考态起源、背景/基底扣除方法及关键测试条件。

## 6. 按理解依赖组织顺序

先给理解下一句所需的信息，再给依赖它的结果。常用顺序是：研究问题、
对象、概念、指标、方法、结果、讨论和结论。详细实现可后移，但正文必须
保留理解结论所需的信息。

## 7. 正向解释与直接表达，同时保持原意和证据强度

用准确名词和动词删除空泛修饰与重复内容。简化时不能把“更多”改成“更强”、
把“相关”改成“导致”，也不能把假设写成事实。

### 正向解释规则

1. **优先正面解释对象、参数、趋势和意义**：
   先说明参数是什么、度量了什么特征、数据反映了什么规律。
   让读者首先建立清晰的图像，而不是陷入连续防御。

2. **含义清楚时即结束句子，不惯例性追加否定式排除清单**：
   避免堆叠“不代表……”“不作为……断言”“不能……”“并非……”等排除性短语。
   含义已完整清晰时即可自然收尾，不预先罗列读者未曾误解的无关可能性。

3. **限制条件集中、自然地说明**：
   限制条件只在会实质改变结论、适用范围或科研判断时保留；放置在句尾或
   段末以自然的一两句话集中陈述，避免穿插在解释主体中打断阅读链条。

4. **改写范式：将连续排除句重构为正向描述与后续证据要求**：
   将“X 不代表 Y；Z 不是 W”等连续否定句式改写为：
   “X 描述……；Z 提供……；若研究 Y/W，需要……证据”。
   明确当前证据覆盖到哪里，若要延伸结论则指出需要何种补充实验或数据支撑。

5. **科学准确性仍然优先**：
   追求正面表述不能为了消除否定句而删除会实质改变结论的科学限制与边界。
   关键边界必须正面交代。

6. **主变化与次变化如实兼顾**：
   主变化和次变化同时存在时，先如实报告两者，再说明贡献大小。例如使用
   “主要由 A 造成，同时伴随较小的 B”，不要用“仅由 A”抹去真实的 B。

## 8. 名称一致且面向读者，彻底清除内部工程代号

正文、图、表和图注对同一对象使用一致名称。严禁在学术论文正文、标题、
表头或图注中残留项目内部任务代号、幻灯片页码或草稿标签（如 `Slide 15`、
`PPT 第 X 页`、`P0 / P1 / P2-A / P2-B / P3`、`Route 1–4`、`Step 1–4` 或中英
混杂的内部流程标签）。统计术语若不能让目标读者立即理解数据如何合并或比较，
应直接写出具体操作。

## 9. 纯正学术期刊连续段落体裁，严禁要点罗列

学术论文的摘要、引言、结果与讨论、结论、实验与计算方法及支撑信息正文
必须全部采用**连续、饱满的学术自然段**展开论述。严禁使用项目汇报式的
无序列表（bullet points）或编号清单来罗列研究内容、机理因素、实验结果
或方法步骤；段落内部与段落之间应通过因果逻辑词自然过渡。

## 10. 多分图视觉回读与“图—注—文—表”四向严格同步

多分图使用清楚可见的 `(a)`、`(b)`、`(c)`、`(d)` 等角标。编写或修改图注与
正文前，**严禁仅凭记忆或旧稿文字推演**，必须逐张打开最终定稿图片执行
视觉回读（Visual Readback）：

1. **逐面板核对角标数量与顺序**：确认图内实际包含几个子面板（如 `(a)–(d)`
   还是 `(a)–(f)`），左到右、上到下各自展示什么内容，严禁将两个独立子图合并
   为一个角标，或将相邻子图内容张冠李戴。
2. **核对坐标轴范围与图内视觉标签（Visual Callout Labels）**：图注和正文中的
   坐标区间、拟合斜率、峰位及柱状图顶部直接印出的数值标签必须与图内实际绘制
   完全一致；表格中以逗号分隔的多项并列序列必须与对应图面板中的模式/样品顺序
   严格一致；同一物理量在全文各章节必须保持统一的有效数字位数。
3. **核对显微镜/光学照片比例尺（Scale Bar）**：如实区分外框主图与内插放大图
   的比例尺数值；若照片未绘制比例尺，严禁在图注中虚构比例尺。
4. **跨批次四向同步**：当图片更新为新一批次计算或实验结果时，必须同步更新
   摘要、正文讨论、图注以及支撑信息数据表中的全部对应数值，确保“图内标注—
   图注—正文—附表”四处零矛盾。

## 11. 方法支持独立复现

按实际流程写明结构和参数来源、模型或力场构建、体系组成、初始构型、
软件与版本、模拟或实验阶段、关键参数、随机性、采样窗口、分析判据、
统计单位和输入输出来源。无法从记录确认的信息应明确缺失，不能凭经验
补写。

正文优先写科学动作和科学上有意义的参数。内部命令开关应翻译为其科学
作用；磁盘路径、哈希、重复映射和调试记录移至补充信息或 provenance。
连续步骤可组织成完整段落，但不能用“采用相同方法”掩盖不同模型、参数
来源或理论层级。

## 12. 软件与方法就近引用

软件、力场、理论方法、基组和关键算法在首次实质出现处引用。优先使用
官方推荐引用、原始方法论文或版本化文档。软件版本和文献版本分别写清；
本地脚本按真实名称和版本说明，不为其虚构论文。

## 13. 保持平实克制的学者文风，杜绝夸张化、绝对化、生造比喻与 AI 套话

科学论文、技术报告与基金/课题申请书必须采用平实、严谨、克制、自然的学者书面语：

1. **去夸张化与去绝对化表述（De-exaggeration & Measured Claims）**：
   - 将“从根本上解释了 / 从根本上克服了 / 从根本上消除了”改为客观的“解释了 / 改善了 / 缓解了”；
   - 将“三支柱动力学微观机理 / 三大支柱”及“第一/第二/第三支柱”改为平实的“微观机理 / 三个方面的因素”及“第一个有利因素 / 第二个因素 / 第三个因素”；
   - 将“彻底打通 / 彻底消除 / 彻底截断 / 彻底失活”“完全囚禁 / 完全锁定 / 完全恢复 / 完全不同”“严格处于 / 直接证明 / 本质区别”改为与证据匹配的客观表述（“改善了连通性 / 缓解了 / 受阻”“主要局域于 / 恢复至接近初始水平 / 明显不同”“分布在…区间 / 表明 / 差异”）；
   - 将“100% 暴露 / 100% 开放 / 零电流”还原为有限样本统计比值（如 `$k/N$`）或精确物理作用范围（如“不参与长程渗流导电”）；
   - 将“全面超越 / 全面降低 / 超长循环 / 极具应用前景”改为“优于 / 在所测条件下均有所降低 / 长周期稳定 / 具有较好的应用潜力”。
2. **严禁生造拟人化/商业化比喻词**：
   解释复杂机制以提高可读性时，只能使用**具体的物理、化学或数学作用过程描述**，严禁使用“实时对账”“死弹簧”“瘦身铠甲”“防弹衣”“记账本”等网络科普腔或 AI 生造比喻。
3. **剔除高频 AI 公文套话**：
   避免使用“全链条闭环”“理论闭环”“完美闭环”“从源头上解决”“无缝衔接”“底层逻辑”“精准赋能”“深耕……领域”“构筑……护城河”等空洞套话。
4. **破除四字联排双引号口号**：
   克制使用“A—B—C—D”式四连破折号双引号造词，还原为自然的学术动宾短语。

## 14. 科研项目申请书（Grant Proposal）大小同行兼顾规范

1. **工程背景转化为具体物理与经济权衡**：
   用具体的空间、厚度、温度、能量密度或成本权衡说明“为什么必须研究该体系”，让大同行一眼看懂迫切性。
2. **核心控制方程就近配备平实导读**：
   在列出核心方程前后，用一两句平实学术语言交代“方程左边算什么、右边哪一项代表什么过程、哪些变量如何耦合演化”。
3. **跨体系前期基础显式建立方法学与结构同源性**：
   当申请人前期代表作集中于相邻体系时，主动说明既有成果与拟研究体系在物理模型、结构拓扑或算法流程上的共性。

## 15. 高倍压缩无损语义核查与顶刊审稿防御准则（跨学科通用）

当把长篇实验/计算详细报告或支撑信息（SI）高度浓缩进主文段落（如 10:1 压缩），或对增量式课题进行顶刊级打磨时，强制执行以下通用准则：

1. **高倍压缩的“有损压缩三项核查（Lossy-Compression Audit）”**：
   - **禁止删定语导致概念退化（No Qualifier Stripping）**：任何带有特定测试条件或理论定义的衍生指标首次进入主文时，必须保留能唯一界定其定义的最小限定词，严禁为了省字将其简写为宽泛上位词（避免该上位词的常规默认单位与文中单位冲突，或与前文另一维度下的同名概念矛盾）。
   - **禁止参数正负号与定性词极性反转（No Sign–Adjective Inversion）**：凡在括号内给出带正负号或方向性的参数时，强制核对其前方的定性形容词（如吸热/放热、吸引/排斥、有利/不利）与该参数的数学定义方向是否严格同向。
   - **禁止单图解读的因果轴串扰（No Single-Panel Causal Contamination）**：围绕某张特定机理子图展开的段落，严格遵循“该子图坐标轴/图例画了什么变量，正文就推导什么因果链”，剔除一切混入括号或挂接在段尾、属于其他子图或补充说明的旁支变量。
2. **先统计分布、后代表性结构，严格区分“单构象极值 vs. 系综均值”及“静态参考态 vs. 动态系综态”**：
   - 展示系综模拟或统计采样结果时，先给出全系综概率密度分布，再给出从分布主峰无偏抽取的代表性结构；
   - 正文中严格区分单结构极值与系综平均值，严格区分 0 K 静态参考几何（如单晶 CIF 或能量极小构象）与有限温度动态系综分布。
3. **增量式工作的“物理探针化”立意与缺失对照预判防御（Pre-emptive Referee Defense）**：
   - 当研究对象属于常规变量微调时，将其定位为“排除其他干扰的干净机理探针（clean mechanistic probe）”，并提炼数据中**违背常规直觉的反常构效悖论（counterintuitive paradox）**作为引言与讨论主线；
   - 当高指标来自多组分/复合体系且缺少某组对称负对照时，在正文开篇主动用已有的基准对照数据证明新组分的本征优势；
   - 当理论模拟与实验相对变化趋势高度吻合时，统一采用克制的学术对标措辞（如 `quantitatively reproducing the experimental enhancement trends` / `in close agreement with`），预防审稿人质疑“事后调参”。

## 最终检查

- 摘要是否讲清研究问题、做法、主要发现和意义，且与正文定量机制首尾咬合？
- 全文是否全部采用连续学术段落，已消除项目汇报式要点列表与内部工作代号？
- 高倍浓缩进主文的物理量是否保留了关键限定词、正负号极性自洽、且无单图因果轴串扰？
- 同一物理量在全文各处的小数位数是否统一，且与图内视觉标签、表格序列顺序完全一致？
- 全文是否已消除夸张与绝对化措辞、生造比喻与 AI 套话，并清除了所有期刊模板残留占位符？
