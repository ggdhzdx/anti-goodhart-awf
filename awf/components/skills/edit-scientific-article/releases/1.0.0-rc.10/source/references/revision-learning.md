# 从用户修改与多轮审稿中提炼可迁移规则

用户修改与多角色审稿反馈是高价值证据，但每一次改句不自动成为普遍规律。使用以下记录和筛选方式：

1. 保存“原句 → 改后句 → 解决的阅读/审稿问题 → 候选通用规则”。
2. **去局域化检验（Domain-Agnostic Filter）**：去掉特定学科的材料名、分子代号、反应路径、模拟软件参数和项目特定结论，检查提炼出的规则能否直接指导催化、电池、光伏、生物材料、机械工程或医学论文写作。
3. 能迁移的内容合并或升级既有规则，避免不断堆叠单项目补丁；不能跨领域迁移的内容留在项目自身的数据约定中，严禁写入通用 Skill 规则。
4. 区分用户明确表达的写作偏好、对科学事实的修正和编辑者自己的建议。
5. 写作偏好可以直接用于表达；科学修改必须与原始数据、方法记录或可靠文献独立核对，不能因措辞更顺而当作事实。
6. 比较用户编辑稿与基线时，以最新用户编辑稿为权威，先识别其新增、删除、合并和重命名，再决定如何继续修改。

可迁移规则应描述普遍的阅读、逻辑推理和证据对齐问题（例如“指标首次出现时先说明怎样理解其增减”“压缩字数时严禁剥离适用边界限定词”），不应写成“某材料的某指标必须增大”或“禁止使用某个特定专业术语”这类项目结论。

## 典型案例一：正面物理意义与限制条件分离

- **原句（负面排除模式）**：
  > 参数 h 仅描述模量随亮度代理量上升的集中程度，不代表反应动力学级数或分子协同性；Emax 为当前模型下的渐近拟合平台，不作为材料物理极限断言。
- **改写方向（正面解释与延伸验证）**：
  > 参数 h = 2.126 描述模量曲线跨过转折区时上升的集中程度。h 越大，模量变化越集中在较窄的掩模亮度范围内。Emax = 695.81 MPa 是当前 12 个等级在本次实验条件下拟合得到的高亮度平台，可用于估计该批薄膜进入模量平台后的代表水平。若进一步讨论反应动力学或分子协同过程，需要结合转化率和分子尺度测量。
- **阅读问题**：
  连续使用“不代表……”“不作为……断言”“不能……”等防御式否定，使读者只知道“它不是什么”，却未能在第一时间直观理解参数本身的物理意义、所反映的数据规律和证据覆盖范围；过多的预设辩解反而降低了科学表达的说服力和流畅度。
- **可迁移规则**：
  1. 科学报告优先正面解释对象、参数、趋势和意义；先陈述物理意义与当前数据证据支持的事实。
  2. 含义已经清楚时结束句子，不惯例性追加否定式排除清单；避免“X 不代表 Y；Z 不是 W”式连续防御。
  3. 将连续排除句改写为三段式正向表述：“X 描述……；Z 提供……；若研究 Y/W，需要……证据”。
  4. 限制条件只在会改变结论、适用范围或科研判断时保留，并集中、自然地说明。
  5. 科学准确性仍然优先，不能为了消除否定句而删除会实质改变结论的限制；当证据有限时，正面阐明覆盖边界与后续验证所需的数据。

## 典型案例二：去除生造比喻与 AI 套话，回归自然学者文风

- **原句（试图通俗化但引入生造比喻与 AI 腔）**：
  > 传统经典分子动力学把化学键简化为预设的“死弹簧”，无法开展“电子-晶格实时对账”，难以形成“第一性原理机理—跨尺度传递—实验验证”的全链条理论闭环。
- **改写方向（平实直观的学者书面语）**：
  > 传统经典分子动力学采用基于基态平衡晶格拟合的固定经验势函数，未能计入高能电子激发引起的反键态布居与成键势能面软化；本课题在每个时间切片重算依赖电子温度的原子受力，并将实时电子温度传入声子热浴的摩擦与随机力项，进而标定经典双温分子动力学物性参数并与离子辐照实验开展定量比对。
- **阅读问题**：
  为了面向大同行“通俗化”而使用“死弹簧”“实时对账”“全链条理论闭环”等拟人化比喻或公文套话，会立刻暴露明显的 AI 生成痕迹，损害基金申请书与学术论文的严肃性与可信度。真正令大同行易读的方式是把抽象术语翻译成**具体的物理动作与因果关系**，而非网络科普比喻。
- **可迁移规则**：
  1. 提高可读性时，用“具体物理量如何变化、哪个方程项受哪个变量控制”替代生造比喻词。
  2. 严禁使用“实时对账”“死弹簧”“瘦身铠甲”“全链条闭环”“从源头上”“无缝衔接”“精准赋能”等典型 AI 套话。
  3. 减少机械对称的四连破折号引号口号，改用自然的动宾短语陈述研究步骤。

## 典型案例三：纯正期刊连续段落体裁、内部工程代号清零与多模态图注视觉回读

- **常见问题（汇报腔要点罗列、内部代号残留与图注失配）**：
  1. 在论文引言、实验方法或支撑信息中使用工作汇报式的 `1. / 2. / 3.` 或无序列表罗列机理支柱与方法参数，甚至残留 `Slide 15`、`PPT 第 9 页`、`P0–P3` 等内部任务代号；
  2. 重新拼装多分图或升级计算批次后，仅凭旧稿记忆编写图注，导致图内实际为 `(a)–(e)` 五个面板而图注只写 `(a)–(d)`、子图 `(c)` 与 `(d)` 顺序颠倒、图内数值更新而正文仍写旧值、或者在无比例尺的实物照片图注中虚构比例尺。
- **改写与核验方向**：
  1. 将所有列表项整合为逻辑连贯的学术自然段，彻底清除 `Slide`、`PPT`、`P0–P3` 等内部代号；
  2. 逐张打开最终嵌入的图片文件，按左到右、上到下顺序核对每个子面板 `(a), (b), (c)...` 的标题、坐标轴起止范围、图内标注数值与比例尺，并同步刷新摘要、正文、图注与附表中的全部数据。
- **可迁移规则**：
  1. 学术论文正文与支撑信息叙述一律采用连续学术段落，严禁使用汇报式要点列表。
  2. 交付前必须对每张最终定稿图执行逐面板视觉回读（Visual Readback），建立“图内面板—图注—正文—附表”四向同步核对表，杜绝凭记忆写图注或跨批次数据混用。

## 典型案例四：去除夸张化与绝对化表述，保持克制客观的学术判断

- **原句（过度夸张与绝对化模式）**：
  > 进一步的动力学计算从根本上揭示了三支柱动力学微观机理，其中第一动力学支柱彻底消除了界面脱溶剂化势垒，第二动力学支柱全面降低了内部重组能，第三动力学支柱使活性位点 100% 暴露，而间位异构体中空穴被完全囚禁，从而直接证明了对位拓扑具有超长循环寿命与极具应用前景的优势。
- **改写方向（克制、客观、与证据匹配的学者书面语）**：
  > 进一步的动力学计算表明，对位拓扑从三个相互关联的微观方面改善了电极反应动力学：第一个动力学有利因素是降低了电极/电解液界面的部分脱溶剂化势垒；第二个动力学因素是在所测试的荷电状态下均降低了内部结构重组能；第三个动力学因素是使所采样的有限构象样本均保持开放（$N/N$），而间位异构体中空穴自旋密度主要局域于端基，从而解释了对位聚合物在长循环中表现出较好稳定性的原因。
- **阅读问题**：
  在学术论文中使用“从根本上解释了”“三支柱动力学微观机理”“第一动力学支柱”“彻底消除”“完全囚禁”“100% 暴露”“全面超越”“超长循环”“直接证明”等夸张或绝对化修饰语，容易引发审稿人对证据边界的质疑并产生宣传腔（overclaiming）。用平实动词与具体统计数字直接陈述数据和趋势，反而更具学术公信力。
- **可迁移规则（跨学科通用）**：
  1. 去掉“从根本上”（`从根本上解释了` $\to$ `解释了`、`从根本上克服了` $\to$ `改善了`）。
  2. 去掉“三支柱 / 三大支柱 / 第一动力学支柱”等宏大造词，改用“三个方面 / 第一个有利因素 / 第二个因素 / 第三个因素”。
  3. 去掉“彻底（消除/打通/截断）”“完全（囚禁/锁定/恢复/不同）”“严格处于”“直接证明”“本质区别”“全面超越”“超长循环”“极具应用前景”等绝对化或拔高词汇，代之以具体数值对比与平实动词。
  4. 将“100% 开放/暴露/一致”还原为有限样本的实际统计比值（如“所采样的 $N$ 个构象中 $k$ 个满足条件（$k/N$）”）。

## 典型案例五：多尺度模拟与支撑信息（ESI）的普适规范提炼

- **常见问题**：
  1. **不透明内部代号与缺少物理译码的专业符号**：正文中直接使用计算簇编号（`C1/C4`）或未给出直观几何图景的专业符号，导致跨领域读者难以理解；
  2. **先个例后统计的倒置叙事与峰值/系综值混用**：先展示单个代表性三维结构，再展示群体统计分布，使代表性结构看似主观挑选；将最优构象峰值与系综平均值并列引用却不注明统计口径；
  3. **多指标跨尺度跳步与模型校准参数披露不全**：从结构指标直接跳到宏观动力学性质而缺少物理桥梁；支撑信息合并简写、表格中混入非目标语言字符。
- **可迁移规则（已去局域化）**：
  1. **专业符号首次出现时的“符号 + 物理图景”双锚定**：保留准确的学科专业符号（不可盲目禁用标准术语），但在首次出现时紧跟一句话物理几何解释；严禁把单张图包含的多个子模态笼统概括为单一模态。
  2. **先统计分布（Population Distribution）后代表性构象（Centroid Structure）**：展示微观结构时，先给出全局概率分布或自由能面，再展示主峰质心对应的代表性三维结构；同时严格区分“最优峰值（Peak/Best）”与“系综均值（Ensemble Average/RMS）”。
  3. **支撑信息（ESI）独立成节、逐符号释义与全英文表格门禁**：每个补充推导或方法模块独立成节，每个方程后紧跟符号定义与物理单位说明，且英文手稿/ESI 表格内严禁残留中文字符（`--require-english-tables`）。

## 典型案例六：字数压缩语义保真、图文跨模态对齐、预防御式审稿闭环与 Word 原生修订批注交付（2026-10-28）

- **发现的核心问题（跨学科共性缺陷）**：
  1. **有损字数压缩（Lossy Compression）**：为了把长文压缩至期刊字数上限，机械删除从句与副词，导致：（a）剥离了成立边界限定词（如将 `nearly identical within the sampled window` 砍成绝对化的 `identical`）；（b）触发“物理量符号—形容词极性反转”（如负值能量越负代表驱动力越强，删词后变成 `a lower (-\Delta E) accelerates...`，造成字面逻辑矛盾）；（c）为省字数将相邻两个子图的独立自变量合并成单句（如将只画了形貌无序度的 `Figure Xa` 写成“形貌无序度与构象熵共同抑制了性质 Y”），污染了单面板因果纯粹性。
  2. **主文—图表—模板跨模态失同步**：图内存在 3 个分组柱状条（或 3 种模式），正文却因为套用固定句式只描述了 2 种；或者直接修改期刊模板稿后，在 Data Availability / TOC 处遗留了 `Deposition numbers xxxxxx`、`Insert text for Table of Contents here` 等未填充占位符。
  3. **对审稿人显性疑问缺乏预防御（Pre-emptive Referee Defense）**：当采用代理模型（如寡聚物截断、隐式溶剂、固定电荷力场、有限时间窗口）或展示局部趋势外推时，若不在正文中主动用半句话点明其适用边界并提供支撑信息（SI）定量敏感性锚点，极易被审稿人以“模型不真实/外推过度”为由拒稿。
  4. **纯文本替换难以直观审阅**：直接输出修改后的终稿 Word，用户无法一眼看出每句话具体删改了哪些词、为什么这样改，也无法在 Word 中逐条点击“接受/拒绝修订”。

- **提炼并固化的四条普适规则（已写入 `edit-scientific-article@1.0.0-rc.10` 与 `build-scientific-docx@1.0.0-rc.12`）**：
  1. **字数压缩的三重语义保真门禁（Lossy-Compression 3-Point Audit）**：
     - **边界限定词不可剥离**：删减冗长句式时，必须保留 `within the sampled window`、`primarily`、`under [condition]` 等界定科学命题成立范围的限定词；
     - **有符号物理量与形容词极性显式绑定**：凡涉及带正负号的差值或对数指标（$\Delta G, \Delta H, \Delta E, \text{p}K_{\text{a}}, \eta$），必须使用物理方向明确的表述（`more exergonic`、`a larger driving force |\Delta E|`、`a reduced barrier \Delta G^\ddagger`），严禁裸用含义模糊的 `higher/lower`；
     - **单子图单自变量因果纯粹性**：概括子图 `(a)` 结论时只能引用子图 `(a)` 坐标轴包含的变量，严禁把子图 `(b)` 的变量提前混入子图 `(a)` 的因果句中。
  2. **多角色（4-Role × 3-Round）循环审稿与预防御闭环**：
     - 面对高标准手稿修订，按 **Role 1（领域大牛：立意与创新度）**、**Role 2（机理与多尺度审稿人：物理自洽与模型边界预防御）**、**Role 3（实验与数据审计员：主文-图-表-SI 100% 同步）**、**Role 4（苛刻副主编：结构节奏、篇幅控制与有损压缩排查）** 执行三轮递进闭环（Round 1 攻克机制硬伤与跨模态错位 $\to$ Round 2 植入方法学预防御句与消除残余绝对化表述 $\to$ Round 3 语言精炼、篇幅达标与模板占位符清零）。
  3. **原位 DOM 编辑规范与残余模板占位符自动拦截（`no_residual_template_placeholders`）**：
     - 在已有 `.docx` 上修订时，严格基于 XML `<w:drawing>` 节点（而非字符串 `'graphic'`）检测内嵌图片段落，动态继承原文档正文字体与行距，且由 `audit_docx.py` 自动扫描并拦截 `xxxxx`、`Insert text for Table of Contents`、`((Maximum ... characters` 等未填充的出版社模板占位符。
  4. **Word 原生修订模式（Track Changes `<w:ins>`/`<w:del>`）+ 右侧中文批注（`<w:comment>`）双交付规范**：
     - 使用 `build_track_changes_docx.py` 调用独立 Word COM 实例执行词级 `CompareDocuments`，并将每处修改的审稿角色、问题诊断、修改策略与数据依据写入对应段落的原生 `<w:comment>` 右侧批注气泡中；交付前通过 `AcceptAll() + DeleteAllComments()` 自动化校验，确保接受全部修订后与净版终稿 **0 字符差异、100% 格式与公式一致**。
